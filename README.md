# 🏠 進階個人房貸試算與財務大師系統 💰

本專案是一個使用 C# Windows Forms 結合 Python 架構開發的**大師級房屋貸款與金融分析系統**。
除了提供直覺快速的每月還款、利息與本金基本試算外，它更整合了八大進階金融工程、AI 演算法與密碼學模型，協助使用者在面對「買房 vs 租房」、「提前還款 vs 投資滾利」等人生重大抉擇時，能擁有最全面的科學化評估數據與視覺體驗。

## ✨ 基本功能特色

- **人性化輸入體驗** — 針對房屋總價與自備款，支援即時動態千分位逗號分隔（如 `1,000,000`），並完美保持打字游標位置，輸入大筆金額不再眼花。
- **精準的資金設定** — 支援房屋總價、固定金額或百分比（%）自備款模式。
- **月付金與總計試算** — 自動換算等額本息條件下的每月應繳金、首期本金/利息，以及總利息支出。
- **寬限期支持** — 可自訂寬限期限，精確計算寬限期內外的每一筆現金流。
- **視窗動態調整** — 支援「自動調整大小」與「手動調整大小」模式切換。

## 🚀 大師級進階金融與 AI 模組

只要在計算完畢後點擊系統下方的 **「🚀 進階大師分析」**，即可啟動八大核心進階模型：

1. **蒙地卡羅 (Monte Carlo / CIR) 利率壓測**：利用隨機漫步模型模擬未來 30 年的百千條升降息路徑，預測極端情況下的房貸負擔能力。
2. **幾何布朗運動 (GBM) 房產溺水風險**：模擬房價下跌導致房屋「資產淨值為負（資不抵債）」的真實崩盤機率。
3. **機會成本與 NPV (淨現值) 評估**：以數學證明「如果不還房貸，把錢拿去投資股市大盤」的總獲利是否能戰勝銀行利息。
4. **現代租買決策數學模型 (DCF)**：精算「租金投資」與「買房資產積累」的淨值現金流折現，尋找出這兩者的黃金交叉年限。
5. **不動產投報率深度運算 (IRR/Cap Rate)**：若不考慮自住而將房屋出租，評估真實的年化資本化率與內部報酬率。
6. **強化學習 RL (Q-Learning) 還款決策樹**：內建輕量級 AI Agent，透過演算法在「保守現金流」與「積極省息」中自我試錯，推演出最佳還款時機。
7. **資安密碼學 (ZKP 零知識證明)**：實驗室等級的隱私驗證，推演如何在不洩漏真實收入餘額數字的情況下，以數學密碼向銀行證明月薪已達放款安全門檻。
8. **AI 房貸健康體檢中心**：將艱澀的數據轉化為白話診斷報告。
   - 提供 LTV (貸款成數) 財務示警與應對建議。
   - **專屬視覺化圖表 (Pie Chart)**：即時根據您的貸款數字，繪製「本金 vs 總利息」的紅綠對比圓餅圖，用強烈的視覺衝擊讓您一眼看清到底有多少錢被銀行賺走，作為抉擇提早還款的最佳輔助工具。

## 🔧 系統需求

- **作業系統**：Windows
- **核心框架**：[.NET 10](https://dotnet.microsoft.com/)
- **開發工具**：[Visual Studio 2026](https://visualstudio.microsoft.com/) 或更新版本
- **環境拓展**：部分外部 AI 演算與 CLI 診斷工具由 Python 環境支援（`financial_advisor.py` 腳本）。

## 📖 操作說明

1. 於主畫面輸入 **房屋總價** 與基本貸款設定（會自動幫您用逗號排版）。
2. 選擇自備款模式並輸入對應數值、年利率與貸款年限。
3. 點擊 **📊 計算** 獲得初步的分攤帳單與帳面數字。
4. 若想進行深度戰略分析，點擊 **🚀 進階大師分析**，系統將自動將您的數據帶入八大金融模型並行運算。
5. 在跳出的進階大師視窗中，透過分頁研讀各項指標，並強烈建議查看最後一頁的 **「AI房貸健康體檢」** 來觀看自己的利息圓餅圖。

## 🧮 基礎計算公式

本系統基底採用 **本息均攤法（等額本息）** 來求取每月理論現金流：

$$M = P \times \frac{r(1+r)^n}{(1+r)^n - 1}$$

> $M$: 每月還款金額 | $P$: 貸款本金 | $r$: 月利率 | $n$: 還款總月數
